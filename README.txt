CV Rika - cara pakai

Buka file index.html dengan browser (klik dua kali). Semua folder harus tetap berada
di dalam folder yang sama, jangan dipisah.

index.html      : isi halaman (semua bagian)
css/            : tampilan, satu file per bagian
                  base.css (warna & font), components.css (kartu, tombol), latar.css (latar halaman),
                  header.css, hero.css (beranda), perkenalan.css, pendidikan.css, hobi.css,
                  idol.css (video latar hanya di sini), kontak.css, animasi.css, zoom.css, responsif.css
js/             : perilaku halaman, satu file per fungsi
                  config.js, footer.js, video.js (video bagian Idol), reveal.js, menu.js, bintang.js, zoom.js
assets/img/     : foto-foto
assets/video/   : video latar bagian Idol

Ganti warna: css/base.css bagian :root.
